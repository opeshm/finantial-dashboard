# Configuración Local de Antigravity / Gemini (`.gemini/`)

Este directorio contiene las configuraciones locales específicas para el proyecto **Financial Dashboard**.

## Estructura de Directorios

- `mcp.json`: Servidores MCP específicos para este espacio de trabajo (ej. PostgreSQL, Angular CLI, Codebase Memory, Netlify).
- `skills/`: Habilidades personalizadas del proyecto (ej. algoritmos de simulación financiera, DCA, verificaciones).
- `rules/`: Reglas de arquitectura, normas de codificación y convenciones para el agente.
- `tools/`: Scripts de utilidad locales (ej. scripts de prueba de base de datos, seeding).

## Servidores MCP Activos
- **codebase-memory-mcp**: Grafo de conocimiento de código para explorar la arquitectura del monorepo.
- **angular-cli**: Ayuda y mejores prácticas para Angular 21 (Zoneless, Signals).
- **netlify**: Gestión de despliegues y servicios.
- **postgres**: Inspección de la base de datos PostgreSQL local (`finantial_dashboard_dev`).
